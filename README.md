# LibertyPlace

Plateforme de streaming indépendante avec liberté maximale et 100% des revenus pour les créateurs.

## Fonctionnalités

- **Liberté de contenu** — Gaming, Casino, IRL, Combat, Porno (18+)
- **100% revenus créateurs** — Aucune commission sur subs et tips
- **Design premium cyber** — Interface dark mode avec glassmorphism et accents néon
- **Pages** — Accueil, Explorer, Catégories, Profil streamer, Dashboard créateur

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000)

## Stack

- Next.js 15 + React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Règles de contenu

Contenu interdit : violence gratuite, meurtres, agressions et contenu non consenti.
